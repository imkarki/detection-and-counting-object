# Object Detection and Counting System
This project performs **real-time object detection and counting (count bottles)** using computer vision and deep learning.  
It detects objects in images or videos and counts how many of each type appear.

## Features
- Detects specific object categories (bottles.)
- Counts detected objects in each frame
- Supports both image and video input
- Can be extended for custom datasets or camera feeds
- Works with YOLO / OpenCV / TensorFlow 

## Tech Stack
- Python 3.13  
- OpenCV  
- NumPy  
- TensorFlow / PyTorch / ultralytics (YOLOv8 or YOLOv5)
